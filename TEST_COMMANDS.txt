          JNMC BELGAUM - CAMPUS NETWORK - TEST COMMANDS
================================================================================

STEP 1: Open the project in GNS3
STEP 2: Start all nodes (Ctrl+A → Right-click → Start)
STEP 3: Wait 5-10 seconds for all nodes to boot
STEP 4: Double-click on a VPCS node to open its console
STEP 5: Run the test commands below

================================================================================
TEST 1: VERIFY IP ADDRESSES
================================================================================

Open each VPCS console and type:
  show ip

Expected output for Admin_PC1:
  NAME        : Admin_PC1[1]
  IP/MASK     : 192.168.100.10/24
  GATEWAY     : 0.0.0.0
  DNS         :
  MAC         : xx:xx:xx:xx:xx:xx
  LPORT       : xxxxx
  RHOST:PORT  : 127.0.0.1:xxxxx
  MTU         : 1500

================================================================================
TROUBLESHOOTING
================================================================================

If ping fails:
1. Make sure ALL nodes are started (green icon)
2. Check IP: type "show ip" in the VPCS console
3. If IP is 0.0.0.0, manually set it:
   - Admin_PC1:    ip 192.168.100.10 255.255.255.0
   - Admin_PC2:    ip 192.168.100.20 255.255.255.0
   - Library_PC1:  ip 192.168.100.30 255.255.255.0
   - Library_PC2:  ip 192.168.100.40 255.255.255.0
   - Hospital_PC1: ip 192.168.100.50 255.255.255.0
   - Hospital_PC2: ip 192.168.100.60 255.255.255.0
   - Hostel_PC1:   ip 192.168.100.70 255.255.255.0
   - Hostel_PC2:   ip 192.168.100.80 255.255.255.0
4. Check links: make sure no link has a red X
5. Restart the node: Right-click → Stop, then Start
